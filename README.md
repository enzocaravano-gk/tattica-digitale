# Tattica Digitale

Web app per digitalizzare gli esercizi di allenamento disegnati a mano su un campo stampato.

**Apri l'app:** https://enzocaravano-gk.github.io/tattica-digitale/

## Come si usa

1. **Modello** — scegli campo intero o mezzo campo e stampa il foglio (A4).
2. Disegna l'esercizio a penna (anche a colori: blu, rosso, nero).
3. **Acquisisci** — scatta la foto del foglio: l'app trova da sola i 4 quadrati neri agli angoli e raddrizza il campo.
4. Dai un nome all'esercizio, poi **Scarica PNG** o **Salva in libreria**.

Le sessioni salvate restano sul dispositivo di chi le crea.
